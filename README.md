# Quant-Project

量化投资策略小组作业：用公开 A 股日频数据研究下跌路径、市场广度与短期反转。

## 从这里开始

1. 阅读 [本地部署指南](SETUP.md)：如何下载、安装依赖、加载数据和确认可以开始测试。
2. 阅读 [HANDOFF.md](HANDOFF.md)：研究问题、实验设计、验收标准和分工。
3. 查阅 [数据说明](data/README.md)：字段、版本、授权及已知风险；[sources.json](data/sources.json) 保存下载地址、文件大小和已知校验值。

```bash
git clone https://github.com/yks23/Quant-Project.git
cd Quant-Project
```

这是纯文档交接仓库，不需要启动服务器，也没有需要执行的自编下载脚本。其他人可以通过上述公开 HTTPS 地址直接 clone，无需配置 GitHub SSH 密钥。

## 两个研究问题

- **下跌路径：** 累计跌幅相近时，一天暴跌与连续阴跌是否具有不同的后续反转？
- **市场广度：** 个股下跌信号在普跌与局部下跌状态下，预测能力是否不同？

## 当前交付边界

仓库提供数据源清单、自然语言部署与校验说明和研究交接方案；不包含原始行情二进制文件，也不包含实证结果。
F.I.R.E. 优先作为字段较完整的研究候选，Qlib 社区数据作为另一套数据处理口径，Zenodo 作为轻量探索备选。
正式选择主样本前，必须验收退市历史、复权、停牌及缺失值。代码许可证不能替代上游数据的再分发许可。
